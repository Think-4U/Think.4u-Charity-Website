Allowed User Request Window

Set the daily time range where users can request custom slots on any day. If the user picks a time in this range, it will bypass strict slot date requirements.

If set, users cannot book/request slots, and coordinators cannot create slots, after this date.

Bulk Slot Generator

Generate recurring coordinator slots iteratively over a specified date range, time intervals, and days of the week.

CSV Bulk Upload

Upload a CSV file with predefined slot schedules to populate coordinator slots directly.

Required CSV Column Headers date,time,duration_minutes,registration_limit,auto_accept

• date: YYYY-MM-DD format (e.g. 2026-07-01)

• time: HH:MM or HH:MM AM/PM format (e.g. 09:30 or 10:00 AM)

• duration_minutes: default 30 (optional)

• registration_limit: default 1 (optional)

• auto_accept: true / false (optional)

Only CSV files are supported

Reschedule Past Meetings

Any scheduled or booked meeting which has not been completed will be rescheduled to the next valid day automatically when loading the portal. You can also trigger this operation manually.

How rescheduling works:

1. Finds any active scheduled or booked meetings with dates in the past.

2. Shifts their date to tomorrow or the next valid day (skipping Sundays and coordinator holidays).

3. Matches the meeting to an available coordinator slot on that day if one exists; otherwise, defaults to the set rescheduled default time.

4. Updates the user's dashboard and sends notification/email updates automatically.
